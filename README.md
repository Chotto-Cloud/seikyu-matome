# 請求まとめ(ふつうの CSV を書き出す練習作品)

あまたある請求書ソフトの中で、どんな自動化ができるかを考えて作った、練習作品です。月ごとの作業の時間や回数(予定と実績)を入れると、**ふつうの CSV**(明細・取引先・品目)に書き出す、小さなWebアプリです。HTMLファイル1つで動きます。

ふつうの CSV で書き出します。お使いの請求書ソフトに CSV の取りこみがあれば、その見本の形に合わせて変えると、請求書の下書きまで自動で作れます(`作り方一式/頼み方_7_自分のソフトに合わせる.md`)。

> このアプリとコードは、作り方の練習として作ったものなので、無料で公開しています。無保証です。

- **特定の請求書ソフトとは無関係の、非公式な補助ツールです。**
- 税・源泉の計算はしません。時間(または回数)と単価を CSV に書くだけです。画面の「金額の目安(単価×数量)」と、明細CSVの「金額(単価×数量・目安)」だけを出します(税の表示や端数処理の設定は反映しません。税は計算しません)。品目ごとに、単位を「時間」か「回」から選べます。
- どのソフトにも合わせていないので、そのままでは、請求書ソフトに取りこめないことがあります。請求書にする前に、中身を必ず自分で確かめてください。

## 画面(版 3.0.0)
上に年と月、実績・予定の合計。「記録を入れる」は「1行で入れる」(例: 10/21 A 作業 9:00-11:00)と「欄に分けて入れる」の2つ。下は「1 予定」「2 実績」「3 書き出す」の3列のカードで、カレンダー(別窓)でも見られます。削除は確かめの窓が出て、行の操作は画面下のお知らせの帯の「元に戻す」で取り消せます。

## 書き出す CSV

| CSV | ファイル名 | 列 |
|---|---|---|
| 明細 | `明細_YYYY-MM.csv` | 請求書番号、発行日、支払期限、取引先コード、取引先、敬称、件名、振込先、日付、サービス、数量、単位、開始、終了、単価、金額(単価×数量・目安)、税区分、源泉徴収、消費税の表示、端数処理、種類(予定/実績) |
| 取引先 | `取引先_YYYY-MM.csv` | 取引先コード、取引先、敬称、消費税の表示、端数処理、登録番号、担当者、部署、メール、TEL、FAX、郵便番号、住所、建物名 |
| 品目 | `品目_YYYY-MM.csv` | 品目、単価(この月)、単位、税区分、源泉徴収 |

- 文字コードは UTF-8(BOMつき)、改行は CRLF です。
- 明細CSVは、1つの記録が1行です。請求書(取引先)ごとにまとまり、日付の順に並びます。
- 取引先CSV・品目CSVには、設定で「請求書ソフトに登録済み」にチェックを付けていない物だけが入ります(二重に登録して、エラーになるのを防ぐためです)。

## 2つの版

| 版 | 場所 | 使い方 |
|---|---|---|
| デモ版 | `docs/index.html`(Webで公開予定) | 決まったダミーの取引先・サービスから選ぶだけ。流れを見るための版です |
| 実用版 | `index.html` | ファイルを自分のPCに保存し、ブラウザで開いて使います |

## 使い方(実用版)

くわしい操作と、すべての機能を1回ずつ試す手順は `使い方とテスト手順.md` にあります。

1. `index.html` を保存し、ダブルクリックでブラウザ(Chrome・Edge)で開きます。インストールは要りません。
2. 画面の「はじめての手順」に沿って、まず **「ダミーを入れて試す」** で流れを見ます。
3. 「3 書き出す」の「明細CSVを保存」を押します。はじめての取引先や品目があるときは、「CSVに書き出す(くわしく)」で、取引先CSV・品目CSVも保存します。
4. 保存したCSVの中身を、表計算ソフトなどで確かめます。
5. 試し終わったら、アプリの「ダミーを消す」を押します。

### 元に戻す方法
- このアプリ: 行の削除や一括の操作は、直後なら「元に戻す」で戻せます。入力の控えは「控え(バックアップ)」で保存・復元できます。

## 自分の請求書ソフトに合わせる

お使いの請求書ソフトに CSV の取りこみがあれば、その見本ファイル(1行目の列名)をAIに渡して、明細CSVをその形に変えると、請求書の下書きまで自動で作れます。手順と頼み方は `作り方一式/頼み方_7_自分のソフトに合わせる.md` にあります。

- ソフトの利用規約を、先に読んでください。
- 本物の取引先名・金額・振込先は、AIに貼らないでください。
- 取りこんでできるのは「下書き」にとどめ、発行する前に、必ず自分で中身を確かめてください。

## データの置き場所と、気をつけること

- 入力した内容は、**あなたのブラウザの中だけ** に保存されます。外へは送りません(ページに通信を禁止する設定 Content-Security-Policy を入れています)。
  - 確かめ方: Wi-Fiを切っても、すべての機能が動きます。
- ブラウザのデータを消すと、入力も消えます。「控え(バックアップ)」で、ときどきファイルに保存してください。
- **ファイルとして開いて使う場合**、保存先は「手元のファイル用」の置き場所です。同じブラウザで開いたほかのHTMLファイルからも、読んだり書きかえたりできる仕組みです(たとえば振込先)。知らない人から受け取ったHTMLファイルを、同じブラウザで開かないでください。明細CSVを保存する前に、振込先を確かめてください。
- 保存したCSVを、Excelなどで開いて保存し直さないでください。文字コードや列の形が変わることがあります。
- 表計算ソフトで開くと、数字の先頭の0が消えることがあります。
- 取引先・品目・件名などが `=` `+` `-` `@` で始まると、表計算ソフトで数式として動くことがあります。そのときは、画面に注意が出ます(止めはしません)。
- 取引先の住所・電話・メールなども入れられます(任意)。入れた内容は、このブラウザの中にそのまま保存され、控えのファイルにも入ります。共用のパソコンでは入れないでください。

## できないこと(限界)

- 税の金額は計算しません。税は品目ごとに選びます(税区分=10%・8%(軽減)・非課税、源泉徴収=なし・10%・10.21%)。明細CSVの「税区分」「源泉徴収」の列に、選んだ物をそのまま書きます。消費税の表示と端数処理は、取引先ごとに選びます。
- 100万円を超える支払いの源泉徴収(20.42%)は扱えません。
- 過去の月を出し直すと、今の税の設定で出ます(単価は「いつから」の履歴で月ごとに出ます)。
- 振込先が前回と違うときの確認は、うっかりした変更を防ぐためのものです。防犯の仕組みではありません。
- 勤怠管理などの記録の取りこみはありません。
- 開始・終了の時刻は、時間の品目で、時間を自動計算するために使い、明細CSVの「開始」「終了」の列にも書きます。日をまたぐ時間は、時間の欄に直接入れてください。

## 開発者向け

- テスト: `node --test tests/app.test.js`(Node.js 20以上。実用版とデモ版の両方を確かめます)
- デモ版を作る: `node tools/build-demo.js`(`docs/` に、デモ版の `index.html` と `_headers` だけを作ります)
- `SHA256SUMS.txt` は、`index.html` と `docs/index.html` のSHA-256(ファイルの指紋)の一覧です。ダウンロードしたファイルが同じかどうかは、`sha256sum -c SHA256SUMS.txt`(Windows の PowerShell なら `Get-FileHash -Algorithm SHA256 index.html`)で確かめられます。
- `sample/明細_見本_A社.csv` は、デモ版のダミーで作った明細CSVの、架空のデータです(テストの見本に使います)。
