# 作り方一式: はじめに

「請求まとめ」(版 3.0.0)を、AI(Claude や ChatGPT など)に**頼むだけで、一から作れる**ようにした資料です。コードは載せていません。仕様(決まり)と、頼み方(プロンプト)を載せています。完成したコードは、答え合わせの見本として、この一式の外(`../index.html`)にあります。

> このアプリと資料は、「あまたある請求書ソフトの中で、どんな自動化ができるか」を考えて作った、練習作品です。特定の請求書ソフトとは無関係の、非公式のものです。無保証です。使うときは、必ず自分で確かめてください。

## 何が作れるか

月ごとの作業の時間や回数(予定と実績)を入れると、どのソフトのものでもない、ふつうの CSV(明細・取引先・品目の3種類)に書き出す、小さな Web アプリです。HTML ファイル1つで動きます。

お使いの請求書ソフトに CSV の取りこみがあれば、その見本の形に合わせて変えると、請求書の下書きまで自動で作れます。変え方は、`頼み方_7_自分のソフトに合わせる.md` にあります。

- 入力した内容は、ブラウザの中だけに保存します。外へは送りません。
- 税と源泉の計算はしません。画面の「金額の目安(単価×数量)」と、明細CSVの「金額(単価×数量・目安)」だけを出します。
- 実用版と、公開用のデモ版の2つが作れます。

## まず、使う道具で選びます

| あなたの AI の道具 | 選ぶ物 |
|---|---|
| **Claude Code のような、ファイルを書き換え、コマンドを自分で流せる道具** | `Code用/頼み方_一気に版.md`(1回渡すと、AI が第1〜6段を順に進めます。テストも AI が流します) |
| **ふつうのチャット**(Claude や ChatGPT の画面に、文を貼る・ファイルを添付する形) | `チャット用/頼み方_1` から順に(6段に分けて頼みます) |
| チャットで、まず小さく試したい | `チャット用/頼み方_軽い版.md`(1回で動く小さな版。1行の読み取り・カレンダー・別窓・デモ版は無し) |

チャットの AI は、作ったコードを動かせないことが多いです。**動かしていないのに、「通りました」と言うことがあります。** そのため、チャット用の各段には、「実行できない場合は『未実行』と書き、私が流すコマンドを出してください。結果は、私が貼ってから判断してください」という一文が入っています。出たコマンドは、自分で流して、結果を AI に貼ってください。

## 中身

```
作り方一式/
  はじめに.md          … このファイル(どちらを選ぶかの案内)
  仕様書.md            … 共通。AI が、これだけで作れる詳しさの仕様。全12章
  確かめ方.md          … 共通。本物のブラウザで確かめる手順、見本との答え合わせ
  tools/               … 共通の小さな道具(Node.js で動く)
    read-sample-header.js   見本 CSV の1行目・BOM・文字コード・改行を、そのまま読む
    check-headers.js        見出しの定数を、仕様書と見本の1行目に1文字ずつ比べる
    compare-csv.js          自分の CSV と見本の CSV を、列ごとに比べる
  チャット用/
    頼み方_1_試作品.md 〜 頼み方_6_テストと見直し.md   第1段〜第6段
    頼み方_軽い版.md   … 1回で動く小さな版
    頼み方_7_自分のソフトに合わせる.md   … おまけ(チャット向け)
  Code用/
    頼み方_一気に版.md   … 1回渡すだけで、第1〜6段を順に進める
    頼み方_7_自分のソフトに合わせる.md   … おまけ(Code 向け。見本との比べ合わせを AI にさせる)
```

| 段 | 何を作るか |
|---|---|
| 第1段 | 30分で動く最小の形 |
| 第2段 | データ・設定・控え・元に戻す |
| 第3段 | ふつうの CSV 3種、警告 |
| 第4段 | 画面(3列、別窓、カレンダー)と1行の読み取り |
| 第5段 | デモ版と、作る道具 |
| 第6段 | テストと、批判的な見直し |
| 第7段(おまけ) | 自分の請求書ソフトの見本ファイルに合わせて、明細CSVの形を変える |

## 使い方

### 作業フォルダーの準備(どちらでも)
1. 空の作業フォルダーを作ります。
2. `作り方一式/` フォルダーごと、作業フォルダーにコピーします。
3. 見本の CSV(`sample/明細_見本_A社.csv`)を、作業フォルダーの `sample/` にコピーします。**開かずに**コピーします。

### チャット用
1. **段ごとに、新しいチャットにします。** 長く続けると、AI が前の決まりを忘れたり、確かめを流したりしやすくなります(試した時、チャットを1つで続けて、第3段の終わりの確かめを流してしまいました)。
2. 各段のファイル(例: `チャット用/頼み方_1_試作品.md`)を開き、「AI に貼る文」を、新しいチャットの本文に貼ります。
3. `仕様書.md` と、**前の段で出来た最新の `index.html`** を、添付します。添付できない AI なら、貼ります(第1段は、仕様書だけです)。
4. AI が `index.html` を作ります。保存して、`確かめ方.md` に従って確かめます。
5. 「終わったと言える条件」がそろったら、次の段の、新しいチャットへ進みます。
6. 第6段まで、順に進めます。第7段(おまけ)は、第6段まで終わってから、必要な人だけ進めます。
7. 各段の最後に、「人が確かめること」があります。必ず自分の目で確かめてから、次へ進んでください。

順番を守ってください。1 → 2 → 3 → 4 → 5 → 6 の順です。前の段が出来ていないと、次の段が壊れます。

### Code用
`Code用/頼み方_一気に版.md` を開き、「AI に渡す文」を Code に貼ります。AI が、各段でテストを流し、合格してから次へ進みます。最後に出る「人が確かめること」(画面の見た目、取りこみ)だけ、自分で確かめます。

## 必要な物

- ブラウザ: Chrome か Edge(本物のブラウザ。確かめ方に理由があります)。
- 文字を書き込めるフォルダー(作った `index.html` を置く場所)。
- AI(Claude や ChatGPT など)。ファイルを直接書き換えられる道具(Claude Code など)だと、貼る手間が減ります。
- **Node.js 20 以上。第3段からは要ります。** 第3段以降は、テストと道具で答え合わせをします。Node.js が無いと、答え合わせができません(第1・2段は、無くても作れます)。

## かかる時間と回数の目安

あくまで目安です。AI やその日の調子で変わります。

**時間の目安: 試した時、チャットで第7段まで、約3時間かかりました(慣れた人の場合)。何日かに分けてかまいません。** 段の終わりで区切って、次の日に新しいチャットで続けるのがおすすめです。

| 段 | 頼む回数の目安(チャット用) |
|---|---|
| 1 試作品 | 1〜3回(30分ほど) |
| 2 データと保存 | 2〜4回 |
| 3 CSV 3種 | 2〜4回 |
| 4 画面と1行 | 4〜8回(3つに分けて頼みます) |
| 5 デモ版 | 1〜2回 |
| 6 テストと見直し | 3〜6回 |
| 7 自分のソフトに合わせる(おまけ) | 2〜4回 |

全部で、ざっと 13〜27 回のやりとりです(おまけの第7段を除きます)。Code用の一気に版は、頼むのは1回ですが、AI が進める時間がかかります。

## AI の出力が途中で切れたら

`index.html` は、完成すると約150KB(2000行ほど)になります。AI の1回の出力に入りきらないことがあります。

- ファイルを直接書き換えられる道具なら、そのまま進められます。
- 貼って使う AI の場合は、「続きを出してください」と頼むか、「変えた関数だけを、置き換え先の関数名つきで出してください」と頼みます。
- 切れたまま保存すると、画面に何も出ません(上に「このアプリのプログラムが、まだ動いていません」と出ます)。そのときは、AI に「最後の `</script></body></html>` まで、完全に出してください」と頼みます。

### 関数の入れ替え方(例)
AI が「関数 `calcHours` を丸ごと入れ替え」と書いて、新しい `function calcHours(…) { … }` を出したときの手順です。

1. `index.html` をエディタ(メモ帳など)で開く。
2. 「calcHours」で検索して、`function calcHours(` の行を見つける。
3. その関数の、始まり(`function` の行)から、終わりの `}`(同じ深さの閉じ)までを、**まるごと選んで消す**。
4. AI が出した関数を、同じ場所に貼る。
5. 保存して、本物のブラウザで開き直す(Ctrl+F5)。テストがあれば、流す。

「名前 のすぐ後ろに足す」と書いてあるときは、その関数の終わりの `}` の次の行に貼ります。`const` の定数は、`const …;` の1文を、まるごと入れ替えます。入れ替えたあとに、画面が何も出なくなったら、`}` の数が合っていません。入れ替える前の保存(コピー)に戻して、やり直します。

## 本物のデータを AI に貼らないでください

- AI に貼ってよいのは、仕様書、前の段のコード、ダミーのデータだけです。
- 本物の取引先名、金額、振込先、住所、電話、メールアドレス、控え(バックアップ)のファイルは、貼らないでください。
- 試すときの名前は、実用版ならダミーA社・ダミーB社・ダミー作業・ダミー相談、デモ版ならA社・B社・作業サービス・相談サービス、振込先は「架空銀行 サンプル支店 普通 0000000」のような、架空のものを使います。
- 資料の例も、すべて架空です。

## 完成見本との答え合わせ

完成見本は、この一式の1つ上のフォルダーにあります(`../index.html`)。**AI は、見本を見られません。** 見本との比べは、人が行います。AI に迷う所を聞かれたら、人が見本で確かめて、伝えます。

- **見た目と動き**: 見本と自分の `index.html` を、並べて開いて比べます。
- **CSV**: 同じ条件で作った明細 CSV が、見本の CSV(`sample/明細_見本_A社.csv`)と1文字も違わないことを確かめます(`確かめ方.md`)。これがいちばん大事な答え合わせです。
- **見出しの行**: `node 作り方一式/tools/check-headers.js index.html 作り方一式/仕様書.md sample/明細_見本_A社.csv` で、3つの見出しの定数を、仕様書の行と見本の1行目に比べます。「すべて同じです」と「飛ばし(skipped): 0件」が合格です。
- **見本のテスト**: 見本のテスト(`../tests/app.test.js`)の、CSV・CSP・innerHTML に関するテストだけを、自分の `index.html` にかけられます(`確かめ方.md` の9)。ID や文言まで見本と同じに作るので、ほかのテストは、完全に通る必要はありません。

## 注意

- 書き出した CSV を、請求書にする前に、必ず自分で中身を確かめてください。
- この一式は、練習として作った非公式のものです。無保証です。
