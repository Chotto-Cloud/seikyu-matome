# 作り方一式: はじめに

「請求まとめ」(版 3.0.0)を、AI(Claude や ChatGPT など)に**順に頼むだけで、一から作れる**ようにした資料です。コードは載せていません。仕様(決まり)と、頼み方(プロンプト)を載せています。完成したコードは、答え合わせの見本として、この一式の外(`../index.html`)にあります。

> このアプリと資料は、「あまたある請求書ソフトの中で、どんな自動化ができるか」を考えて作った、練習作品です。特定の請求書ソフトとは無関係の、非公式のものです。無保証です。使うときは、必ず自分で確かめてください。

## 何が作れるか

月ごとの作業の時間や回数(予定と実績)を入れると、どのソフトのものでもない、ふつうの CSV(明細・取引先・品目の3種類)に書き出す、小さな Web アプリです。HTML ファイル1つで動きます。

お使いの請求書ソフトに CSV の取りこみがあれば、その見本の形に合わせて変えると、請求書の下書きまで自動で作れます。変え方は、最後の `頼み方_7_自分のソフトに合わせる.md` にあります。

- 入力した内容は、ブラウザの中だけに保存します。外へは送りません。
- 税と源泉の計算はしません。画面の「金額の目安(単価×数量)」と、明細CSVの「金額(単価×数量・目安)」だけを出します。
- 実用版と、公開用のデモ版の2つが作れます。

## 中身

| ファイル | 何か |
|---|---|
| `はじめに.md` | このファイル |
| `仕様書.md` | AI が、これだけで作れる詳しさの仕様。全12章 |
| `頼み方_1_試作品.md` | 第1段: 30分で動く最小の形 |
| `頼み方_2_データと保存.md` | 第2段: データ・設定・控え・元に戻す |
| `頼み方_3_CSV3種.md` | 第3段: ふつうの CSV 3種、警告 |
| `頼み方_4_画面と1行.md` | 第4段: 画面(3列、別窓、カレンダー)と1行の読み取り |
| `頼み方_5_デモ版.md` | 第5段: デモ版と、作る道具 |
| `頼み方_6_テストと見直し.md` | 第6段: テストと、批判的な見直し |
| `頼み方_7_自分のソフトに合わせる.md` | おまけ: 自分の請求書ソフトの見本ファイルに合わせて、明細CSVの形を変える |
| `確かめ方.md` | 本物のブラウザで確かめる手順、見本との答え合わせ |

## 使い方

1. 必要な物をそろえます(下)。
2. `頼み方_1_試作品.md` を開き、「AI に貼る文」を AI に貼ります。**その後ろに `仕様書.md` の全文を続けて貼ります**(ファイルを添付できる AI なら、添付でもかまいません)。
3. AI が `index.html` を作ります。保存して、`確かめ方.md` に従って確かめます。
4. 「終わったと言える条件」がそろったら、次の `頼み方_2` へ進みます。第2段からは、**前の段で出来た `index.html` の全文も、あわせて貼ります**。
5. 第6段まで、順に進めます。第7段(おまけ)は、第6段まで終わってから、必要な人だけ進めます。
6. 各段の最後に、「人が確かめること」があります。必ず自分の目で確かめてから、次へ進んでください。

### 順番を守ってください
1 → 2 → 3 → 4 → 5 → 6 の順です。前の段が出来ていないと、次の段が壊れます。

## 必要な物

- ブラウザ: Chrome か Edge(本物のブラウザ。確かめ方に理由があります)。
- 文字を書き込めるフォルダー(作った `index.html` を置く場所)。
- AI(Claude や ChatGPT など)。ファイルを直接書き換えられる道具(コードを書く用の AI アプリなど)だと、貼る手間が減ります。
- Node.js 20 以上(第5段・第6段のテストを流すとき。無くても、第1〜4段は作れます)。

## かかる回数の目安

あくまで目安です。AI やその日の調子で変わります。

| 段 | 頼む回数の目安 |
|---|---|
| 1 試作品 | 1〜3回(30分ほど) |
| 2 データと保存 | 2〜4回 |
| 3 CSV 3種 | 2〜4回 |
| 4 画面と1行 | 4〜8回(3つに分けて頼みます) |
| 5 デモ版 | 1〜2回 |
| 6 テストと見直し | 3〜6回 |
| 7 自分のソフトに合わせる(おまけ) | 2〜4回 |

全部で、ざっと 13〜27 回のやりとりです(おまけの第7段を除きます)。

## AI の出力が途中で切れたら

`index.html` は、完成すると約150KB(2000行ほど)になります。AI の1回の出力に入りきらないことがあります。

- ファイルを直接書き換えられる道具なら、そのまま進められます。
- 貼って使う AI の場合は、「続きを出してください」と頼むか、「変えた関数だけを、置き換え先の関数名つきで出してください」と頼みます。置き換えるときは、同じ名前の関数を丸ごと入れ替えます。
- 切れたまま保存すると、画面に何も出ません(上に「このアプリのプログラムが、まだ動いていません」と出ます)。そのときは、AI に「最後の `</script></body></html>` まで、完全に出してください」と頼みます。

## 本物のデータを AI に貼らないでください

- AI に貼ってよいのは、仕様書、前の段のコード、ダミーのデータだけです。
- 本物の取引先名、金額、振込先、住所、電話、メールアドレス、控え(バックアップ)のファイルは、貼らないでください。
- 試すときの名前は、実用版ならダミーA社・ダミーB社・ダミー作業・ダミー相談、デモ版ならA社・B社・作業サービス・相談サービス、振込先は「架空銀行 サンプル支店 普通 0000000」のような、架空のものを使います。
- 資料の例も、すべて架空です。

## 完成見本との答え合わせ

完成見本は、この一式の1つ上のフォルダーにあります(`../index.html`)。

- **見た目と動き**: 見本と自分の `index.html` を、並べて開いて比べます。
- **CSV**: 同じ条件で作った明細 CSV が、見本の CSV(`../sample/明細_見本_A社.csv`)と1文字も違わないことを確かめます(`確かめ方.md`)。これがいちばん大事な答え合わせです。
- **見出しの行**: 仕様書第4章に写した3つの見出しは、見本の `HDR_LINES`・`HDR_CUS`・`HDR_ITEM` と1文字も違いません。自分のコードの見出しの行を、仕様書の行と比べてください。
- **見本のテスト**: 見本のテスト(`../tests/app.test.js`)を、自分の `index.html` にかけられます(`確かめ方.md`)。ID や文言まで見本と同じに作るので、完全に通る必要はありません。落ちた所は、見本と違う所を見つける手がかりです。

## 注意

- 書き出した CSV を、請求書にする前に、必ず自分で中身を確かめてください。
- この一式は、練習として作った非公式のものです。無保証です。
