# 頼み方(チャット用): 軽い版

## この版は何か
**1回の返事で動く、小さな版**を作ります。段に分けず、チャットを1回(または、続きを2〜3回)で終わらせます。まず小さく試したい人、全部を作る時間が無い人向けです。

作る物と、作らない物は、次のとおりです。

| 作る | 作らない |
|---|---|
| 記録を入れる(欄に分けて入れる形だけ) | 1行で入れる欄(1行の読み取り) |
| 取引先ごとにまとめる(金額の目安 = 単価×数量) | カレンダー |
| 明細 CSV を書き出す(見本と1文字も違わない形) | 別窓(削除・取引先・品目。削除は確かめの文で足りる) |
| ブラウザの中に保存する(開き直しても残る) | デモ版、控え(バックアップ)、元に戻す、一括の操作、ダミーを入れる |
| 警告(止める物と、※で通す物の一部) | 取引先 CSV、品目 CSV、単価の履歴、ダークの色 |

あとで全部を作りたくなったら、`頼み方_1` から順に進めてください。軽い版の `index.html` は、第2段以降の元にはなりません(作り直しになります)。

## 1回の返事に入る大きさの目安
`index.html` は、**約700行・40KB 以内**を目安にします。入りきらないときは、AI に「続きを出してください」と頼むか、`はじめに.md` の「関数の入れ替え方」の形で、変えた関数だけを出してもらいます。

## 貼る物
**新しいチャットを開きます。** 次を添付(または貼る)します。

1. 下の「AI に貼る文」(本文)
2. `仕様書.md`
3. 見本の CSV(`sample/明細_見本_A社.csv`。1つ上のフォルダーの `sample/` にあります)

あわせて、見本の CSV を自分の作業フォルダーの `sample/` に同じ名前でコピーし、`作り方一式/tools/` の道具も置いておきます(確かめで使います)。

## 人が確かめること
`確かめ方.md` の1・2・4に従います。

1. 本物のブラウザで開く。Console に赤いエラーが無い。
2. ダミーで、見本と同じ条件(仕様書4.2)の記録を入れ、明細 CSV を保存する。`作り方一式/tools/compare-csv.js` で、見本と比べる(振込先だけ「…0000001」にして、`--allow=8`)。
3. 保存した CSV を、Excel などで開いたら、保存し直さずに閉じる。
4. Wi-Fi を切っても動く。

## うまくいかないとき
- 途中で切れて、画面に何も出ない: 「最後の `</script></body></html>` まで、完全に出してください」と頼みます。
- 見本と1文字違う: `確かめ方.md` の方法で、違う箇所を見つけ、その箇所だけを AI に伝えます。
- 自分のソフトに合わせたい: `頼み方_7_自分のソフトに合わせる.md` に進めます。ただし、元は軽い版でも、見出しの定数 `HDR_LINES` と `invoiceCsv()` があれば合わせられます。
