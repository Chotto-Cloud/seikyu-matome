## 終わったと言える条件
次が全部そろったら、次の段へ進みます。

- [ ] `index.html` を保存して、ダブルクリックで開くと、画面が出る(上に黄色い「プログラムが、まだ動いていません」が残らない)。
- [ ] 日付・取引先・サービス・時間を入れて「追加する」を押すと、カードが「1 予定」か「2 実績」に出る(今日より後の日付は予定、今日までは実績)。
- [ ] 欄を空のまま押すと、赤い警告の吹き出しではなく、`#fmsg` の文が出る。
- [ ] 「実績にする」「予定に戻す」で、カードが列を移る。「削除」で確かめが出て、消える。
- [ ] 月を替えると、その月の行だけが出る。頭の実績・予定の合計が合う。
- [ ] ページを開き直しても、行が残る。
- [ ] コードに、次が無い: `innerHTML`、`fetch(`、`http://`・`https://`、`<script src=`、`<link`。CSP の meta が仕様書の行と同じ。`const DEMO=false;` が1か所だけ。

## 人が確かめること
`確かめ方.md` の「1. 本物のブラウザで開く」に従います。

1. Chrome か Edge でファイルを開く。
2. ダミー(例: ダミーA社、ダミー作業、1.5時間)で3行ほど入れる。
3. Wi-Fi を切っても動く。
4. F12 で開発者ツールを開き、Console に赤いエラーが出ていない。

## うまくいかないとき
- 何も出ない: 上に黄色い枠が出ていれば、スクリプトが途中で切れているか、文法の誤りです。Console のエラーの文を AI に貼って、直してもらいます(エラーの文に本物のデータは入りません)。
- 画面が出ても押せない: AI の「プレビュー画面」で開いていませんか。本物のブラウザで開き直してください。
