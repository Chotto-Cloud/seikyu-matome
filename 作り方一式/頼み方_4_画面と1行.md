## 4-2 1行で入れる

### AI に貼る文

```
あなたは、Webアプリを作る手伝い役です。私は初心者です。分かりやすい日本語で答えてください。

「請求まとめ」を6段に分けて作っています。今は第4段の2つ目(4-2、1行で入れる)です。

【従う所】第8章の8.4の「1行の箱」、第9章(全部)。

【やること】
1. 1行の読み取り parseLine(text, mo) と、lineCheck()、行を1行の文にする lineOf(r)。決まりは仕様書第9章のとおり(日付・時間帯・数量・予定/実績・名前の当て方・時間の品目と回の品目の違い)。名前の比べ方は squash / key / baseKey / matchNames。
2. 1行の欄 #q、読み取りの札 #qRead、押すと欄に入るボタン #pickClients #pickServices(最大8つ。押すと key の形で差しこむ)、「くわしい入れ方」。

4. 欄 ⇔ 1行の切りかえ: 欄→1行は lineOf、1行→欄は読めた分を欄へ。直す時は、欄にも1行にも中身を入れる。
5. 足したあと、行の月へ表示を移し、帯に「(11月に移りました)」を足す(6.4)。

- 欄と1行で、同じ形の行が出来る。
- lineOf の結果を parseLine に通すと、同じ中身に戻る(時間帯あり、なし、2回)。
- 入れ方の切りかえが seikyu-matome-input-v1 に覚えられ、保存に失敗しても壊れない。アプリのデータの保存場所は増えない。

```
